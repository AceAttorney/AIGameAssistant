# 游民星空 源详述

## 擅长
- 宝可梦系列（图文并茂、分页详细、截图丰富）
- 主流主机/掌机游戏中文攻略
- 老游戏的攻略积累深厚（GBA/NDS/PSP时代）

## 不擅长
- 英文游戏名搜索（返回空）
- 冷门独立游戏
- 会返回视频攻略（标题含"视频"，内容为空）——脚本自动跳过

## 特征
- 多页攻略（10-50页），脚本自动合并前5页
- 图片懒加载（data-src），脚本已修复提取真实URL
- 页脚噪音自动清洗（责任编辑、页码导航、投票）

## 使用方式
- `walkthrough_search.py --game "中文名" --keyword "关键词" --source gamersky`
- 或 `--source all` 让脚本优先搜游民
