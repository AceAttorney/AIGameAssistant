# DuckDuckGo 搜索引擎兜底 源详述

> 当游民星空、Archive.org、Reddit 均无结果时，DuckDuckGo 作为最后兜底。

## 擅长
- 中文游戏攻略搜索质量远超 Bing（不会分词拆散）
- 能搜到游侠网、巴哈姆特、知乎等不在直接源列表中的攻略站
- 非 JS 渲染，可直接 HTTP 抓取

## 不擅长
- 结果质量不稳定，依赖搜索引擎排名
- 需要代理访问

## 使用方式
- `walkthrough_search.py --game "游戏名" --keyword "关键词" --source search`
- 脚本内部调用 DuckDuckGo HTML API
