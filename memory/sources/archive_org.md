# Archive.org 源详述

## 擅长
- 怀旧/经典游戏的官方攻略书（Prima/BradyGames/Nintendo Power）
- 英文游戏名搜索命中率极高
- 攻略内容权威性最高（官方出版印刷品扫描）

## 不擅长
- 中文游戏名搜索（归档以英文为主）
- 太新的游戏（攻略书出版需要时间）

## 使用方式
- `walkthrough_search.py --game "英文名" --keyword "walkthrough" --source archive`
- 返回 `archive_id` 字段，需下载 DjVuTXT 提取文本
- 格式优先级: DjVuTXT > OCR Search Text > EPUB
