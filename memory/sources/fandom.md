# Fandom / 专有Wiki 源详述

> 此源通过 `wiki_search.py` 的路由表命中，不是 walkthrough 源。

## 擅长
- 通过路由表匹配的游戏：恶魔城、宝可梦(52poke)、原神、星铁、绝区零、塞尔达等30+ IP
- 英文内容详尽，结构化好
- 52poke(神奇宝贝百科): 宝可梦种族值/招式表/进化链

## 不擅长
- 中文游戏名（需路由表匹配或 AI 翻译）
- 太冷门的游戏（没有 Wiki 站点）

## 使用方式
- `wiki_search.py --game "中文名或英文名" --topic "关键词"`
- 脚本自动匹配路由表 → 命中后直连专有Wiki API
