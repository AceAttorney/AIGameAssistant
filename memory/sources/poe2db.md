# POE2DB 源详述

> 流放之路2 专用数据库。结构化游戏数据（技能宝石、装备、词缀），非文本攻略。

## 擅长
- 技能/辅助宝石的具体数据（伤害、消耗、属性需求）
- 装备词缀查询
- 游戏机制数值查询

## 不擅长
- BD攻略/Build指南（需要 DuckDuckGo 搜索社区攻略）
- 非 JS 渲染的搜索（`/cn/search?q=` 返回首页，疑似需要浏览器渲染）

## 使用方式
- 路由匹配: `wiki_search.py --game "流放之路2" --topic "技能名"`
- DuckDuckGo 兜底时 poe2db.tw 优先
- 对于 BD 攻略类问题，建议直接走 `walkthrough_search.py --source search`
